All notable changes to IDJINKOUNDZI NEWS will be documented in this file.

## [1.0.0] - 2026-01-02

### Added
- 📰 News feed with filtering by event type
- 📅 Appointment booking system
- ✉️ Contact form with service selection
- 👤 User profile management
- 🔐 Email/password authentication with Supabase
- 👻 Guest mode for browsing news
- 🌓 Dark and light mode with smooth transitions
- ✨ Animated splash screen with creator attribution
- 📜 Terms and conditions screen with mandatory acceptance
- 🎨 Premium editorial-style design system
- 📱 Bottom tab navigation
- 🔄 Pull-to-refresh functionality
- 💾 Persistent session storage
- ⚡ Smooth animations with React Native Reanimated
- 🎯 Loading skeletons for better UX
- ❌ Error handling with retry functionality
- 📭 Empty states with helpful messages

### Technical
- Built with Expo SDK 54
- React Native 0.76.5
- TypeScript 5.3
- Expo Router 4.0 for navigation
- Supabase backend integration
- Zustand for state management
- React Native Reanimated for animations
- Full EAS Build configuration
- Android 16 KB page size compatibility
- Hermes JavaScript engine enabled
- Row Level Security (RLS) on all database tables
